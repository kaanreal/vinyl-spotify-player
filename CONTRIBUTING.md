# Contributing to Vinyl Spotify Player

Thanks for checking out this project! Whether you're fixing a bug, adding a feature, or just experimenting, contributions are welcome.

## Quick Start

1. **Fork the repo** on GitHub
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/vinyl-spotify-player.git
   cd vinyl-spotify-player
   ```
3. **Set up your environment**:
   - Windows: `.\scripts\install.ps1`
   - Mac/Linux: `./scripts/install.sh --pc`
4. **Make your changes**
5. **Test it**: `.\scripts\run-dev.ps1` or `./scripts/run-dev.sh`
6. **Commit and push**:
   ```bash
   git add .
   git commit -m "Add: brief description of changes"
   git push origin main
   ```
7. **Create a Pull Request** on GitHub

## What to Work On

### Easy Improvements
- Add more keyboard shortcuts
- Support different display sizes
- Add more color themes
- Improve error messages
- Fix typos in documentation

### Medium Improvements
- Add playlist controls
- Display song lyrics
- Add equalizer visualization
- Support multiple languages
- Add configuration GUI

### Advanced Improvements
- Hardware integration for Raspberry Pi
- Custom animations and transitions
- Advanced audio visualizations
- Mobile app companion
- Multi-room synchronization

## Code Style

Keep it simple and readable:
- Use clear variable names
- Add comments for complex logic
- Follow existing code patterns
- Test your changes before submitting

## Questions?

Open an issue on GitHub or check existing issues for help!
